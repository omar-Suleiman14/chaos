# Learn UI acceptance checks

Scope: Opus frontend continuation on the durable Chaos backend. AI editing and the internal Tutor remain disabled; selected-context external handoff stays explicit.

Run these after the combined implementation and automated checks. A checked automated test is not a real-phone or screen-reader certification.

- Blank signed-in account: Learn home, empty Courses/Saved/Library, manual New Lesson and error/loading recovery.
- Editor: paragraphs/headings/table/equation/YouTube; keyboard undo/redo; Arabic direction; source upload/image paste/drop; source permissions and citation navigation.
- Lifecycle: autosave → reload → private/public publication → draft edits leave publication unchanged → restore history; two-device stale writes retain recoverable text.
- Library: nested folders/move/cycle errors; existing form/quiz membership; collection editing; module follows and curriculum version labels.
- Reader: outline navigation/focus, light/dark/reduced motion, mobile overflow, media captions/alt/lightbox and keyboard actions.
- Private study: save/highlight/note and remove, refresh/reopen on another session, no public annotation exposure.
- Practice: multiple assessments, normal form/classic quiz launch/fork routes, eligible Live links, weak-concept evidence and empty evidence states.
- Verification: student/educator claims submitted to backend, status/expiry shown independently of content review; no retained identity scans.
- Connections: explicit asset selection and scopes, revocation, provenance/open-app links; distinguish already-applied draft comparison from proposals awaiting approval.
- Classroom: supported team creation/join/results and deadline/attempt-bound homework submission with upload errors; analytics suppression/empty states.
- External handoff: exact preview/optional context, keyboard radio controls, clipboard failure and external-window behavior.
- Keyboard/screen reader/phone: focus order/traps/return focus, labels/announcements, touch controls, 320/390/768-pixel layouts and Arabic content.

Blocked contract or operator-dependent checks must be recorded as unfinished, with no disabled control presented as delivered functionality.

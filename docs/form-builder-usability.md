# Form builder acceptance flow

Use a new account and a blank form on phone and desktop. The primary navigation is Questions, Theme, Settings and Publish; Preview remains a header action. Logic, Translate, Team and History are under More.

1. Add a question from Questions.
2. Switch to Theme and select a theme.
3. Open Preview and answer the question, then close it.
4. Publish from the header or Publish view after reviewing validation.
5. Copy the public share link from Publish.

Check keyboard focus, Arabic layout, narrow screens, validation blockers and draft saving. Advanced options remain available without crowding the primary flow. This is an acceptance script, not a claim that a usability study has been completed.

# Chaos public positioning

Chaos is one workspace for forms, quizzes, live games, lessons and courses. Public courses are free to read. /learn is the public Explore destination, using the native public course directory and published lesson search; it does not require dashboard sign-in. Its directory is bounded and must not be described as an exhaustive catalogue.

Manual creation and editing are the default product path. Chaos has no required internal AI workflow. ChatGPT is an optional external connection, available on every Chaos plan; external provider access and terms are separate. Do not describe the app as Pro-only or guarantee store approval or availability from local code alone.

Registered course tools support drafts, metadata, outlines, lesson drafts and explicit publication. Publishing a course also publishes its outlined lessons. Review before publishing. Public courses are free; private course publication requires Business. Imported content stays a draft for review, and private source material must only be shared deliberately.

Public copy must reflect registered capabilities. Avoid “cannot delete anything”: lesson draft-block deletion exists. Public SEO and course directories depend on the anonymous backend's publication and privacy checks, using immutable published metadata. Do not market draft content or private records as public.

Landing uses existing Chaos typography, feature cards and link styles. Explore appears in desktop/mobile navigation, footer and hero, with one dedicated section for native courses and lesson search. English and Arabic copy should remain aligned.
